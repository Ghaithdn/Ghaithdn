## Featured Project

### 🧑‍💼 [RecruitAI](https://github.com/Ghaithdn/recruitment-ai) — Intelligent Recruitment Platform

Full-stack AI platform that automates CV screening with NLP: it extracts text from PDFs, vectorizes it with sentence-transformers and scores each candidate against a job offer using cosine similarity (60% semantic + 40% skill overlap). It includes role-based access (recruiter/candidate), JWT authentication, PDF upload with validation and an analytics dashboard.
